# Разбор ковра на части: что не работает и как двигаться (2026-10-29)

## Диагноз по данным (бэкап cps-data от 29.10)
- 4155 фото, скрыто 95. Размечено 67 ковров, 1347 рамок: ✓ 522, ✗ 128, ждут 697. Из ✓ — 254 без имени.
- 30 названных элементов, почти у каждого образцы с 1–3 ковров (dəvə — 2 ковра, qeyçi — 3, остальные — 1).
- Зоны (layout) размечены у **3** ковров из 4155. Тип (comp) в бэкапе ни у одного.
- Самопроверка детектора «эталоны» (`etalon_eval.json`): recall 0–6 % у dəvə, qeyçi, kilimgülü; 29 % у qapı naxışı. То есть детектор по образцам **не работает**, и не из-за настроек (пять вариантов A–E дают одно и то же).
- Школа по фото: 86 % против 78 % «всегда Губа-Ширван» — почти ничего.

## Почему уперлись
1. **Учим на 1–3 коврах и проверяем на другом ковре.** Для этого никакой детектор не обобщится: другой масштаб, другая съёмка, другая цветность. Нужны либо десятки ковров на элемент, либо задача попроще.
2. **Ищем именованные элементы раньше, чем разобрали ковёр.** Все модули (повторы, поиск по схеме, DINOv2-окна, эталоны, SAM) работают на сыром фото в перспективе, где один и тот же элемент имеет разный размер и наклон. Выпрямления ковра нет нигде в коде, симметрия не используется.
3. **Семь способов, ноль мерила.** rug_match, motif_search, shape_hint, sign_lab, sign_lib, etalon, sam_seg — каждый эвристика, и только у etalon есть численная проверка (и она показывает ноль). Нельзя понять, что помогло.
4. **Открытое множество.** Искать элемент среди ~1300 рисунков Керимова на всём каталоге — заведомо трудно. У Керимова же каждый тип ковра — закрытый список из 3–15 элементов.

## Принцип дальше: сначала грамматика, потом имена
Ковёр — почти всегда симметричен (две оси зеркала, часто поворот на 180°), каймы — фризы с периодом, поле — либо решётка с периодом, либо медальон + углы. Это даёт разбор **без базы и без имён**: любой ковёр → зоны → повторяющиеся единицы → экземпляры. Имя потом ставится один раз на единицу, а не на 28 рамок.

### Этап 1. Выпрямление и зоны (2–3 недели)
Цель: у каждого целого ковра — четыре угла, выпрямленная картинка, границы полос (внешняя кайма, главная кайма, внутренние каймы, поле), для медальонных — медальон и углы.
- Инструмент «4 угла» (человек ставит/подтверждает) → гомография → `rect/<id>.jpg` (нормированный ковёр, сторона 1600).
- Границы полос — **симметричный профиль**: складываем профиль цвета/контуров с четырёх сторон (левый+правый, верх+низ) — один профиль вместо 32 кольцевых участков (см. HANDOFF_rugs §6). Правка одной линии двигает все четыре.
- Симметрия: оси зеркала по минимуму разницы с отражением; центр; «складка» в четверть.
- Медальон/гёль: область вокруг центра, замкнутая контуром, симметричная по обеим осям; углы — то, что остаётся в поле вне решётки.
- Обучаемая часть: на 150–200 подтверждённых зон — DINOv2-патчи + линейная голова на классы {фон, внешняя кайма, главная кайма, малая кайма, поле, медальон, угол}. Это простая задача для DINOv2, в отличие от элементов. Самопроверка: IoU по классам, ковры по типам отложены.
- Что получаем сразу: «где бордюр, где гёль», правильный масштаб для всего остального, число и ширина кайм как признак типа (у Керимова число кайм описано по типам).

### Этап 2. Разбор на единицы (3–4 недели)
- Каймы: `sign_lab` уже находит период и раппорт; переносим на выпрямленный ковёр (период станет стабильным) и добавляем проверку по симметричной паре (левая = правая).
- Поле-решётка: 2D-автокорреляция выпрямленного поля → векторы решётки → ячейка-единица (медиана всех ячеек = «чистая» единица) → все экземпляры. Для «сдвинутых» рядов — косая решётка.
- Поле-медальон: единицы = медальон, его половина/четверть по осям, угловые лячаки, заполнение между ними (по повтору).
- Узлы: шаг узла по FFT на выпрямленном фото → единица в клетках → пиксельная схема (1 клетка = 1 узел) → сравнима с рисунками Керимова напрямую, в одном масштабе.
- Результат — «паспорт разбора» ковра: зоны, список единиц (вырезка, схема в узлах, где повторяется, положение). Хранить в `data/parse/<id>.json`. Это и есть «расшифровать все ковры и разобрать на элементы» — без имён, на всех целых коврах, ночью.

### Этап 3. Имена: закрытый список по типу (параллельно с 2)
- Для ковра известного типа (тип — по подписи, по двойнику, по числу кайм и решётке, позже по набору единиц) список кандидатов = элементы этого типа у Керимова (3–15 штук, 86 типов уже связаны с 487 схемами). Задача «какой из 8» решается даже простым сравнением схем в узлах (единица ковра в клетках ↔ рисунок Керимова), с поворотами/отражениями, по форме без цвета.
- Рисунки Керимова для сравнения с фото: рендер «под шерсть» (клетки → размытие, палитра красителей из `dyes.json`, шум), так ищем не чертёж на фото, а похожую вырезку.
- Без типа: единицы всех ковров кластеризуем (как `sign_lib` для кайм): одна группа = один знак; человек называет группу; по знакам угадываем тип и школу (мешок знаков → тип; подписи типов уже известны: Пиребедиль = dəvə+qayçı и т. д.).
- Накопится 20+ ковров на элемент — тогда уже имеет смысл учить детектор по образцам (сейчас — нет).

### Что делать с существующими модулями
- Оставить: sign_lab/sign_lib (перевести на выпрямленный ковёр), SAM (контур единицы), DINOv2-индекс (кластеры единиц и голова зон), find_repeats (внутри выпрямленного ковра — лучше станет само).
- Заморозить: etalon (детектор по образцам) до накопления образцов; find_schemes_auto, shape_hint — заменяет закрытый список по типу.
- Ввести единое мерило: **контрольный набор** 20 ковров (по 2–4 на тип: Пиребедиль, Гаджигайыб, Салахлы, Шыхлы, Фахралы, Мараза, Алпан + 2 медальонных + 2 карабахских), размеченных полностью (углы, зоны, единицы, имена). Каждый шаг проверяется на нём: IoU зон, доля найденных единиц, доля верных имён. Без цифры на этом наборе ничего не считаем улучшением.

## Порядок работ (первые 2 недели)
1. Выбрать 20 контрольных ковров (грейд A, крупное фото) — человек, 1 вечер.
2. Инструмент «4 угла» + выпрямление + симметричный профиль кайм — машина; человек проверяет на 20 коврах.
3. 2D-решётка поля и фризы кайм на выпрямленном ковре → единицы; экран «Разбор ковра» (зоны + единицы + экземпляры), кнопка «назвать единицу» (имя на все экземпляры).
4. Шаг узла + схема в узлах у единицы; сравнение с рисунками типа (закрытый список) → подсказка имени.
5. Ночной разбор всех целых ковров → в «События»: сколько разобрано, где не нашли симметрию (фрагменты, безворсовые, сцены).
Этапы 1 и 3 (закрытый список) — самый быстрый путь к «связи с Керимовым»: на керимовских коврах тип известен, элементы перечислены, остаётся сопоставить единицы и схемы.

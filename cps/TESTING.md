# CPS — автотесты

`cps/tests/run_tests.py` поднимает студию **на временной копии кода** с тестовыми данными (рабочие данные не трогаются),
открывает её в Chromium (Playwright) и проходит экраны: нажимает кнопки и горячие клавиши, рисует рамки мышью, проверяет API.
Любая ошибка JavaScript на странице — тоже падение теста.

## Запуск
Из корня репозитория:
```
pip install -r cps/requirements.txt playwright
python3 -m playwright install chromium
python3 cps/tests/run_tests.py
```
- `--only rug` — только тесты, в названии которых есть `rug`;
- `--keep` — не удалять временную папку с данными (путь печатается в конце).

Результат: `прошло N, упало M`, код выхода 0 / 1. Скриншоты каждого шага и `server.log` — в `cps/tests/out/` (в git не идут).
Упавший тест сохраняет `FAIL_<имя>.png` — что было на экране в момент падения.

На GitHub то же самое запускается само на каждый push в `cps-v5` (`.github/workflows/cps-tests.yml`, вкладка Actions);
скриншоты — в артефакте `cps-test-screenshots`.

## Что проверяется
| Тест | Что |
|---|---|
| `t01_load` | страница грузится без ошибок JS, версия рядом с логотипом, шапка в одну строку |
| `t02_tabs` | все вкладки открываются без ошибок |
| `t03_pattern_hotkeys` | редактор узора: Tab, B/P/E/G/F/L/R/C, цифры, X, U, `]`, Esc |
| `t04_rug_grid_and_editor` | плитка ковров, открытие, рамка мышью, H/B/Z, Esc, Tab, C, X, цифры зон, Delete |
| `t05_rug_passport_popup` | паспорт ковра во всплывающем окне (кнопка и I), Esc и «Закрыть», правка сохраняется на сервере |
| `t06_rug_statusbar` | ‹ N / M › в строке состояния, ← → и `[` `]` — соседний ковёр |
| `t07_rug_split_keeps_passport` | разделение разворота: паспорт и подписи частей, правка разделения не теряет рамки |
| `t08_api` | основные API отвечают |

## Тестовые данные
- `make_rugs()` — синтетические ковры: разворот Керимова на 2 ковра с подписями `page_figs`, пара двойников (Керимов + «Метрополитен», фото крупнее), 6 ковров «V&A».
- `make_crops()` — сканов в git нет, поэтому для каждого рисунка из `data/work` рисуется серая «вырезка» нужного размера.
- Сервер стартует без пароля (`CPS_PASSWORD` пустой) и с `CPS_RUGS_TEST=1` (разрешает «⟳ из Диска» брать пакет по локальному пути — для будущего теста синхронизации).

## Правила (для всех чатов, которые меняют CPS)
1. **Перед коммитом** — `python3 cps/tests/run_tests.py`, всё зелёное. Если упало — чинить код, а не тест (тест меняется, только если поведение меняется сознательно — и это пишется в README).
2. **Новая функция интерфейса или клавиша → новый тест** (или строка в существующем) в том же коммите. Клавиши перечислены в `DESIGN.md` §3.
3. Проверять **состояние** (`S.…`, `R.…`, ответ API), а не только «кнопка нажалась». Сообщение `assert` — по-русски и говорит, что сломалось («клавиша U не включает подложку»).
4. Ждать через `pg.wait_for_timeout` с запасом — сервер на CI медленнее.
5. Посмотреть скриншоты в `tests/out/` глазами, если менялся вид.

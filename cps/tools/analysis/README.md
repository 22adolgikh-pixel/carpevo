# Скрипты разбора качества автомата (v10.11)

Данные: ветка `cps-data` (work + crops), разверните её, например `git worktree add /tmp/cd origin/cps-data`, или задайте `CPS_ANALYSIS_DATA=<путь к папке data>`.
Промежуточные файлы пишутся в `/tmp/cpsan_*`. Запуск из этой папки, порядок:

1. `ev.py` — автомат по всем принятым ч/б, сравнение с итоговыми матрицами → `cpsan_ev.csv`, `cpsan_lost_gray.csv` (принятые без серого, где автомат видит >10% серого).
2. `bench.py` — кэш (`cpsan_bench.pkl`) и функция `score(D, clean)`: честная оценка любого варианта `autogrid.clean` (серое: пропущено/лишнее, контур, рисунков с ошибкой >10%).
3. `variants.py` — проверенные варианты закрытия разрывов контура (все хуже базы, отвергнуты).
4. `regds.py` — датасет «замкнутая область → серая/нет» (+ текстура), в разборе классификатор не дал выигрыша.
5. `risk.py` — признаки «серое под вопросом» (AUC 0,66, не внедрено). `cat.py` — откуда берутся ошибки серого. `val.py` — связь меры искажения с ошибкой. `viz.py <id…>` — картинка «оригинал | авто | эталон».
Скрипты — исследовательские, не часть студии: короткие, без тестов.

# Проба: узнаёт ли модель зрения-языка элемент Керимова на фото (2026-10-30)

Данные: 80 вопросов из ✓ рамок со схемой (18 ковров, 29 схем; vlm_probe.py, VP_EXPORT=1).
Вопрос: вырезка рамки с фото + панель из 8 схем (одна верная). Отвечали 4 агента Claude Sonnet по 20 вопросов, ключа не видели.

| вариант | верно с 1-й | в двух лучших | уверенность ≥ 0.75 |
|---|---|---|---|
| лёгкий: 7 чужих схем случайно | 85 % (68/80) | 95 % | 26 из 26 верно |
| трудный: 7 самых похожих по силуэту из 1114 схем | 70 % (56/80) | 94 % | 21 из 21 верно |
Случайно — 12,5 %. Стоимость ≈ 330 тыс. токенов на 80 вопросов (≈ 4 тыс. на вопрос), 40 с параллельно.

Выводы:
- Имя элемента по закрытому списку модель даёт надёжно; уверенные ответы (≥ 0.75, четверть всех) — без ошибок → их можно принимать автоматически, остальные — человеку с двумя вариантами (там верный в 94 %).
- Ошибки сосредоточены на мелких вырезках (cm_25129c6ea0: элементы t101_f01 по 30–40 px) — это качество фото, а не модель.
- Не проверено: поиск элемента на целом ковре без рамки (проба VP_FULL=1 — следующая); ковры без известного типа.

## Проба «без рамки» (целые ковры, 18 шт., 268 ✓ рамок)
Модель получила фото с сеткой 10 % и список схем: элементы ковра + подложенные похожие (3–14 схем). 3 агента Sonnet.
- Назвала элементы, которые есть на ковре: 40 из 43 (93 %). Но «нашла» и 32 подложенные схемы (точность «есть» 56 %) — часть из них, возможно, действительно есть на ковре и не размечена (нужна проверка человеком).
- Рамки: 47 % ваших рамок накрыты рамкой модели с тем же именем (по центру), 73 % — рамкой любого элемента; 69 % рамок модели для верных элементов попали в вашу рамку. Положение грубое (сетка 10 %).
- Вывод: «что есть на ковре» модель отвечает хорошо, «где именно» — приблизительно; точные рамки — SAM/поиск повторов по подсказке модели.
- Проверка человеком — интерактивная страница (артефакт «Проба узнавания узоров», решения в коллекции `verdicts`).

# Carpet Pattern Studio v5

Запуск: двойной клик по `start.command` (или `pip install -r requirements.txt && uvicorn backend:app --port 8000`), затем http://localhost:8000

Сканы кладутся в `scans/` (или папку из `CPS_SCANS`, например Google Drive).

1. **Листы** — автопоиск рамок рисунков, правка, номер таблицы, **сложность** каждого рисунка (1 простой · 2 средний · 3 сложный · 4 ультра — клавиши 1–4 на выделенной рамке, выделение само идёт дальше) → «Сохранить и нарезать».
2. **Геометрия и сетка** — 4 угла (перспектива/поворот), контраст/яркость/гамма, авто-сетка, шаг/начало/кол-во клеток, тоны и пороги, превью.
3. **Пиксели** — инструменты иконками (подсказки при наведении), схема краёв матрицы (▲▼◀▶: зелёная — добавить ряд, красная — убрать, Shift — ×5), **пробел (удерживать) — подглядеть скан**; подписи и привязка к странице сайта, «✓ Готово → след.».
4. **Каталог** — все рисунки с фильтром по сложности, пакет JSON для сайта, легенда CSV, загрузка готовых рисунков.

На экранах 2–4 левой панели нет: рисунки листаются в шапке (‹ › или `[` `]`, ⏭ — следующий неготовый, выпадающий список — быстрый переход).

**⚡ Авто: сетка и пиксели** (`autogrid.py`). На экране «Листы» — кнопка «⚡ Авто: сетка и пиксели»: нарезает лист (если ещё не нарезан) и для каждого рисунка сам находит шаг сетки, наклон и углы, переводит клетки в пиксели и сохраняет как черновик (значок ⚡). Рисунки, где пиксели уже есть, не трогаются (Shift+клик — пересчитать все). На экране «Сетка» — кнопка «⚡ Авто» для одного рисунка. Дальше — проверка на «Пикселях» (пробел — подложка) и «✓ Готово → след.».
**По умолчанию — только тёмный контур** (флажок «+ заливка»/«+ серая заливка» включает старое поведение с серым тоном). Контур совпадает с ручной разметкой (45 рисунков, табл. 9–18, 63) на ~100 % (кроме табл. 13, где клетки рисунка не совпадают с миллиметровкой); серая заливка ~92 % — часто проще докрасить вручную, поэтому она теперь не включена по умолчанию.

## v5 (2026-09-26)
- **Инструменты рисования** — вертикальная колонка иконок слева от холста на экране «Пиксели» (карандаш/ластик/заливка/пипетка/линия/прямоугольник/копирование, отмена/повтор, зеркала).
- **Копирование области** (иконка / клавиша `C`): выделить прямоугольник → он в буфере → клик(и) вставляют его в другое место (пригодится для симметричных/повторяющихся частей сложных узоров). `Esc` — отмена.
- **Ось симметрии двигается**: `Alt` + тянуть по красной линии — сдвинуть её, если она встала не по центру рисунка.
- **Палитра компактнее** — квадратики без названий (клик — выбрать цвет, кружок в углу — сменить, ✕ при наведении — удалить), как в Photoshop.
- **Обрезка по рамке автоматически** при каждом сохранении рисунка — руками жать «обрезать» больше не нужно.
- **Статус рисунка**: кроме «✓ Готово → след.» (идёт в пакет для сайта) — «⚠ На пересмотр → след.» для сложных рисунков, которые хочется отложить, но не терять из виду (фильтр «⚠ на пересмотр» в каталоге).
- **Источники (книги/журналы) на «Листах»**: сканы группируются по подпапке в `scans/` — переключатель сверху списка листов показывает по одной книге/журналу за раз, когда источников больше одного.
- Убрана лишняя кнопка «← сетка» на «Пикселях» — переключение экранов уже есть в шапке (`1–4`, `[` `]`).

**Названия.** Основное название — `name_az` (азербайджанская латиница). Если в легенде его нет, берётся черновик из кириллицы книги (`name`) — поле подсвечено пунктиром, проверьте и поправьте. Подбор страниц сайта идёт по `name_az` + кириллице + русскому переводу (`az_names.py`: Ağac = Агадж = агач). В пакете для сайта `name` = `name_az`, книжная запись — в `name_book`.

**Сетка отдельно.** `data/out/<id>_x12.png` — чистый рисунок без сетки (фон прозрачный), `<id>_grid.png` — сетка отдельным прозрачным слоем того же размера, SVG — без сетки. Старые выгрузки перерисовываются автоматически при первом запуске v4.

Результаты: `data/out/` (PNG 1:1, PNG ×12, SVG), `data/work/` (настройки и матрицы).
Легенда подписей: `data/legend.csv` (табл. 13–17 уже внесены). Индекс страниц сайта: `data/site_index.json`.

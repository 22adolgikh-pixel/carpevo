# Carpet Pattern Studio v5

Запуск: двойной клик по `start.command` (или `pip install -r requirements.txt && uvicorn backend:app --port 8000`), затем http://localhost:8000

Сканы кладутся в `scans/` (или папку из `CPS_SCANS`, например Google Drive).

1. **Листы** — автопоиск рамок рисунков, правка, номер таблицы, **сложность** каждого рисунка (1 простой · 2 средний · 3 сложный · 4 ультра — клавиши 1–4 на выделенной рамке, выделение само идёт дальше) → «Сохранить и нарезать».
2. **Геометрия и сетка** — 4 угла (перспектива/поворот), контраст/яркость/гамма, авто-сетка, шаг/начало/кол-во клеток, тоны и пороги, превью.
3. **Пиксели** — инструменты иконками (подсказки при наведении), схема краёв матрицы (▲▼◀▶: зелёная — добавить ряд, красная — убрать, Shift — ×5), **пробел (удерживать) — подглядеть скан**; подписи и привязка к странице сайта, «✓ Готово → след.».
4. **Каталог** — все рисунки с фильтром по сложности, пакет JSON для сайта, легенда CSV, загрузка готовых рисунков.

На экранах 2–4 левой панели нет: рисунки листаются в шапке (‹ › или `[` `]`, ⏭ — следующий неготовый, выпадающий список — быстрый переход).

**⚡ Авто: сетка и пиксели** (`autogrid.py`). На экране «Листы» — кнопка «⚡ Авто: сетка и пиксели»: нарезает лист (если ещё не нарезан) и для каждого рисунка сам находит шаг сетки, наклон и углы, переводит клетки в пиксели и сохраняет как черновик (значок ⚡). Рисунки, где пиксели уже есть, не трогаются (Shift+клик — пересчитать все). На экране «Сетка» — кнопка «⚡ Авто» для одного рисунка. Дальше — проверка на «Пикселях» (пробел — подложка) и «✓ Готово → след.».
**По умолчанию — только тёмный контур** (флажок «+ заливка»/«+ серая заливка» включает старое поведение с серым тоном). Контур совпадает с ручной разметкой (45 рисунков, табл. 9–18, 63) на ~100 % (кроме табл. 13, где клетки рисунка не совпадают с миллиметровкой); серая заливка ~92 % — часто проще докрасить вручную, поэтому она теперь не включена по умолчанию.

## v8 (2026-09-29): цветные схемы и раппорт кайм
- **⚡ цвет** (`autocolor.py`). Переключатель «авто / ЧБ / цвет» рядом с кнопкой ⚡ (на листе и на рисунке). В режиме «авто» цветной рисунок распознаётся сам.
  - Шаг сетки ищется по границам цветных пятен (тест Рэлея), а не по линиям бумаги. Клетки бывают прямоугольными: в табл. 164 это 12.4×8.3 px. Узкие вертикальные каймы в книге напечатаны повёрнутыми, это учитывается.
  - На листе два прохода. Сначала каждый рисунок считается сам по себе, затем узкие полосы пересчитываются с шагом, найденным на уверенных рисунках листа.
  - Цвет клетки берётся как медиана Lab в центре клетки. Фон ищется отдельно, остальные цвета собираются k-means. Близкие оттенки сливаются, «рассыпанные» оттенки (шум печати) сливаются с соседним цветом.
  - Названия цветов подбираются по словарю красителей (az/ru, `DYES`). Фон — индекс 0.
  - Если авто разделило один цвет на два, задайте «цветов N» и нажмите «↻ цвета».
  - Если сетки нет (фото ковра, как табл. 204 «Джек»), пиксели не делаются, а рисунок помечается как фото.
- **Раппорт кайм** (`rapport.py`). Считается для полос (длина ≥ 1.9 ширины) или для рисунков, у которых в разделе стоит «кайма» / «бордюр». Пересчитывается при каждом сохранении пикселей.
  - Шаг повтора ищется по силуэту (весь рисунок или один цвет). Чистый фрагмент получается голосованием по повторам.
  - Клетки, расходящиеся с большинством, попадают в `suspect_cells`: это кандидаты в ошибки оцифровки.
  - Найденная симметрия записывается в `is_mirror` / `is_glide`.
  - Хранится в `work.rapport`; файл `_unit.png` — один повтор ×12. `POST /api/rapport/{id}` пересчитывает раппорт вручную.

## v10 — ускорение обработки массива
- **Вкладка «5 · Очередь»** (клавиша 5): авто-результаты, ещё не принятые человеком, мозаикой от надёжных к рискованным; порог риска,
  «выбрать надёжные», «✓ принять выбранные» (`POST /api/accept`). Пустой результат («рисунок не найден») получает риск 1.5 и не попадает в «надёжные».
- **Риск и симметрия** (`risk.py`): при автооцифровке ищется зеркальная/поворотная симметрия; если рисунок почти симметричен (≥90%),
  клетки, её нарушающие, подсвечиваются оранжевыми рамками в «Пикселях» (клик по «◇ симметрия» — скрыть). На 404 ЧБ-рисунках:
  среди подозрительных клеток доля реально исправленных человеком 12% против 0,8% в среднем (в ~15 раз выше случайного).
  Риск = 1 − уверенность + флаги + нарушения симметрии. `POST /api/risk_backfill` досчитывает для старых.
- **Ночной прогон** (`/api/prowl/start|stop`, `GET /api/prowl`): в фоне «Авто» на всех нарезанных, но не оцифрованных рисунках; прогресс в правой панели очереди.
- **Модель клеток ЧБ** (`learn.py`): нейросеть (numpy) на окне 5×5 нормированной яркости, учится на готовых рисунках.
  `docker exec deploy-cps-1 python learn.py eval|train`; сохраняется в `data/cell_model.json` только если в кросс-проверке по рисункам лучше порогов.

## v10.3 — вкладка «⚙ Конвейер»
Стартовая вкладка повторяет 5 шагов: (1) листы → автоматическая разметка рамок (`segment_sheet`, номер таблицы по странице) → (2) оцифровка + оценка сложности/цвета/симметрии/риска → (3) проверка списка с массовым «принять надёжные» / «на доработку» → (4) ручная доработка рискованных → (5) дообучение модели ЧБ-клеток. `/api/pipeline` — сводка, `/api/prowl/start {stages:[segment,auto]}` — запуск, `/api/review_mark` — пометка на пересмотр. Оценка сложности — эвристика (по числу чёрных клеток и цветов), не откалибрована. Авторазмеченные листы не проверены глазами.

## v10.4 — повторы и фото
- `dupes.py`, `GET /api/dupes`: поиск повторов узоров по силуэту «не фон» (48×48, 8 поворотов/отражений, допуск по пропорциям). На конвейере — блок «≈ Повторы узоров». Это кандидаты: решает человек. Объединение/пометка «то же, что …» пока не делается.
- Фото ковров: если автосетка не найдена, «⚡ Авто» спрашивает число клеток по ширине и усредняет цвет по заданной сетке (`autocolor.forced_grid`, `/api/auto {cols,rows}`). Уверенность ≤ 50%, `source_kind: "photo"`. Не сделано: выравнивание перспективы, поиск ковра на странице, распознавание повторов поля, привязка к 144 типам.

## v10.5 — интерфейс: Рисунки, быстрая проверка, геометрия поверх
- Вкладки: ⚙ Конвейер · 1 Листы · **2 Рисунки** (очередь проверки + каталог на одном экране, переключатель сверху) · 3 Пиксели. «Геометрия и сетка» — кнопка справа в шапке, открывается поверх любого экрана (клавиша G; Esc/повторный клик — вернуться туда, откуда открыли).
- Очередь: при наведении на карточку — оригинал рядом с результатом; стрелки — по карточкам, Пробел — отметить, A — принять, X — на доработку, Enter — править.
- «▶ быстрая проверка»: рисунки по одному на весь экран (слева оригинал, справа результат): A принять, X на доработку, → пропустить, ← назад (отменяет принятие), G — сетка, Enter — править, Esc — выйти. `/api/accept` принимает `value:false`.
- Хоткеи 1/2/3 = Листы/Рисунки/Пиксели.

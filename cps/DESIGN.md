# CPS — дизайн интерфейса (с v11.0)

Утверждённая концепция — Design-артефакт «CPS — новая концепция интерфейса» (7 экранов: Узоры · редактор, Узоры · обзор,
Красители, Ковры · обзор, Ковры · редактор, Паспорт, События и автоматика). Этот файл — правила, по которым её переносим в `index.html`.

## 1. Стиль: как интерфейс Figma
Все цвета — переменные в `:root` в начале `index.html`. **Новых жёстко прописанных цветов в разметке не добавлять** — только `var(--…)`.

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#1e1e1e` | фон страницы |
| `--canvas` | `#1a1a1a` | рабочая область под сканом / фото (canvas, `#rgView`) |
| `--pan` | `#2c2c2c` | панели, шапка, строка состояния |
| `--pan2` | `#383838` | поля ввода, кнопки |
| `--sel` | `#444444` | наведение, выделенная строка |
| `--ln` / `--ln2` | `#3e3e3e` / `#4d4d4d` | линии / рамки полей |
| `--tx` / `--mut` | `#ffffff` / `#b3b3b3` | текст / второстепенный |
| `--acc` + `--acc-tx` | `#ffffff` + `#1e1e1e` | главное действие и включённая кнопка: белая с тёмным текстом |
| `--zog` | `#b8323f` (кизиловый) | заливка: «нужно ваше решение», «в работе» (значки, счётчик колокольчика) |
| `--warn` | `#f0707e` | текст предупреждений (⚠ источники расходятся, фрагмент…) на тёмном фоне |
| `--ok` / `--bad` / `--blue` | `#7ec96b` / `#e06c75` / `#6cb6ff` | готово / ошибка, удалить / ссылки, фокус поля |

- Шрифт — **Inter** (Google Fonts, запасной — системный), моно — системный `ui-monospace`.
- Кизиловый — редко: только то, что ждёт человека. Обычный акцент — белый.
- Цвета разметки **поверх фото и сканов** (рамки элементов, зоны `RZ`, ручки углов) — функциональные, остаются яркими (жёлтый, голубой…), это не тема.
- Эмодзи в новых элементах не использовать; старые убираем по мере переделки экранов.

## 2. Оболочка — одинаковая для узоров и ковров
1. **Шапка**: слева лого, версия (`#appVer`) и кнопка пользователя (`#userchip`) — в одной строке (тест: шапка < 70 px); посередине — разделы; справа — действия экрана.
2. Узкая колонка разделов слева (`#rail`, 64 px): Обзор, Листы, Узоры, Ковры, Красители; внизу — «Клавиши» (шпаргалка, клавиша `?`). Кнопки сохраняют старые id (`#tab-pipe`, `#tab-sheet`, `#tab-queue`, `#tab-rugs`, `#tab-dyes`). В шапке посередине — «где вы сейчас» (`#crumbs`, обновляется сама).
3. Левая панель — файлы того, что открыто: у «Узоров» — дерево источник → таблица со счётчиками (фильтр списка), у «Ковров» — источники (вид → музей) и школы галочками, у редактора ковра — инструменты и узоры на ковре.
4. Центр — рабочая область; инструменты — полоской над ней (план: плавающей снизу).
5. Правая панель — **свойства выбранного** (у ковра — выбранная рамка; если ничего не выбрано — короткая карточка ковра и кнопка «Паспорт»).
6. Внизу — **строка состояния `#sbar`** в обоих редакторах: у узоров — отмена, ‹ › рисунки, сообщение, координаты, масштаб; у ковров (`#rgSb`, класс `body.rugmode`) — ‹ N / M › ковёр, название, число рамок / проверенных, сообщение, фоновые задачи.
7. **Паспорт** — всегда во всплывающем окне `#modal` (кнопка «Паспорт» над рабочей областью или клавиша I у ковров). Esc / «Закрыть» / клик мимо окна — закрыть. Правки сохраняются сразу.

## 3. Горячие клавиши (не терять! каждая проверяется тестом — см. TESTING.md)
Клавиши читаются по физической клавише (`kk(e)` → `e.code`), поэтому работают в любой раскладке (рус/азерб/англ).

**Везде**: `?` — шпаргалка клавиш · `1` / `2` — Листы / Узоры (вне редактора) · `+` `−` — масштаб · `0` — вписать · пробел (держать) — двигать / подглядеть скан · Cmd/Ctrl+Z, Shift+Cmd+Z, Cmd+Y — отмена/повтор · Cmd+S — сохранить · Esc — закрыть окно / редактор.

**Редактор узора**: Tab — Геометрия ↔ Пиксели · `[` `]` — соседний рисунок · Q (геометрия) — углы ↔ сетка · Cmd+' — сетка ·
B/P — перо · E — ластик · G/F — заливка · L — линия · R — прямоугольник (ещё раз — с заливкой) · C — копировать область (затем клик — вставить) ·
`1`…`9`, `0` — цвет (1 — фон) · X — предыдущий цвет · U — подложка скана · Cmd+Enter — «✓ Готово».
**Очередь проверки**: стрелки, Enter, пробел, A (принять), X, O. **Быстрая проверка**: → / пробел — пропустить, ← / Backspace — назад.

**Экраны «Красители» и «События»**: Esc — закрыть; клавиши редакторов на них не действуют.

**Редактор ковра**: B — рамка · H — рука · F/0 — вписать · Z — поле и каймы (ещё раз — выйти) · I — паспорт ·
← → или `[` `]` — соседний ковёр плитки · Tab / Shift+Tab — следующая/предыдущая рамка · C — верно · X — неверно ·
`1`…`8` — зона (поле, медальон, угол поля, главная кайма, малая кайма, бордюрная, торцевая, другое) · R — повтор · J — тот же узор, что… ·
U — отделить от повторов · Q — повернуть схему 90° · W — зеркало · S — схема поверх фото · D — фокус · G — найти этот узор на других коврах · E — вижу ещё (повторы с порогом ниже) · K — несколько ковров на фото (разделить) · пробел (держать) — спрятать рамки · Delete — удалить рамку · Esc — снять выделение / выйти из режима.

Новая клавиша → добавить сюда, в подсказку `data-tip` кнопки и в тест.

## 5. Единая палитра красителей (v11.1)
- Библиотека — `data/dyes.json` (правится на экране «Красители», копируется в cps-data). У красителя `hex` — как он показывается везде, `scan` — как выглядит в выцветшей печати (по нему автомат узнаёт краситель; при первом запуске = старый `hex` из `dyes.json` в коде).
- В рисунке у цвета: `palette_dyes[i]` (id), `palette_link[i]` (цвет из библиотеки), `palette_scan[i]` (замер со скана), `palette[i]` — итоговый цвет (по нему рисуются выгрузки). Расчёт — `dyes.resolve()` на сервере и `resolvePal()` в редакторе (одинаковый, проверяется тестом t09).
- Несколько цветов одного красителя в рисунке — оттенки: цвет библиотеки, сдвинутый по светлоте (шаг 10 L*) в том же порядке, как они светлее/темнее на скане; подписи «zoğalı», «zoğalı 2».
- Плитка палитры в редакторе: белая точка — цвет связан с палитрой; «?» — автомат предложил краситель, человек не подтвердил (кнопка «✓ принять предложенные»). Свой цвет (пипетка) снимает связь.
- Смена цвета красителя → фоновая перекраска всех связанных рисунков и их выгрузок (`/api/dyes`, ход виден на экране «Красители»).

## 6. Центр событий и автоматические задачи (v11.2)
- Колокольчик рядом с пользователем: кизиловый счётчик — пункты «Нужно решение» уровня «нужно»; белая точка — есть «можно» или новое в «Система». Опрос раз в минуту (`/api/events/count`).
- Экран «События»: слева «Нужно решение» / «Система» / «Люди», справа автоматические задачи (включена, «без вопросов», день и час) и отчёт за неделю / 30 дней.
- «Нужно решение» не хранится, а пересчитывается раз в минуту поставщиками в `backend.py` (`@events.provider`): дообучение (порог 10 — можно, 100 — нужно; `CPS_TRAIN_CAN`/`CPS_TRAIN_NEED`), листы, нарезанные машиной (пока рисунки листа никто не смотрел), надёжные рисунки, двойники ковров, неподтверждённые красители, ошибка резервной копии. «Скрыть» прячет пункт, пока не изменится его состояние (`sig`).
- «Система» — `data/events.jsonl`: `events.add(title, body)` из любого места кода (итог прогона, обучение, перекраска, недельный отчёт).
- Задачи: `events.automation(id, title, rule, run, due, ask, …)`. «Без вопросов» — сервер делает сам, когда `due()`; без галочки — пункт в «Нужно решение» с кнопкой (`ask()`). Сейчас: ночной прогон (03:00, без вопросов), дообучение (спросить), отчёт за неделю (пн 09:00). Настройки — `data/events_state.json`. Время — Баку (`CPS_TZ_HOURS`). `CPS_NO_SCHED=1` — задачи не запускаются сами (тесты).
- Новый поставщик / задача → тест в `t11`.

## 7. Редактор ковра по зонам и пояснения в «i» (v11.9)
- **Слева — «Узоры»** (`rugLeft`): вкладки «На ковре» (элементы этого ковра) · «Керимов» (элементы типа ковра; выбор типа — сначала типы школы ковра; «найти все элементы Керимова на фото») · «Похожие» (по форме на выбранную рамку, `#rgShape`; открывается сама, когда выбрана рамка без названия) · «Все схемы» (поиск по готовым схемам студии; клик — назначить выбранной рамке, без рамки — обвести на фото; можно перетащить). Название ковра здесь не повторяется — оно только в «где вы сейчас».
- **В центре** — фото и плавающая панель инструментов над ним посередине (`.rgtb`): рамка / рука / вписать | повтор, найти повторы, вижу ещё, на других коврах (активны, когда выбрана рамка) | Паспорт (единственная кнопка паспорта) | масштаб, «сохранено», «⋯» (несколько ковров, не подходит, поле и каймы, цвет рамок, затемнение). Строка под панелью (`#rgHint`) — только в особых режимах (разделение, зоны, «обведите…», «тот же узор, что…») и «на фото, похоже, N ковра».
- **Справа — только выбранная рамка**: картинка, название, статус; ✓ / ✗ / ↺; Узор (словарь, схема, поворот, наложение); Зона; Отличие от образца; Повторы (предложения машины — одной строкой кнопок); «Ещё» (уверенность, тот же узор, отделить, удалить); комментарий.
- Строка состояния — номер ковра и счётчики, без названия; сообщения машины — коротко («найдено повторов: N»), подробности — в правой панели.
- **Пояснения**: любой текст-объяснение — `<span class="hint">…</span>`, он сам прячется за кнопку «i» (`hintsToI`, наблюдатель на весь документ). Состояние и данные (пусто, ошибка, путь листа, «ждут авто: 3») — `class="info"`, видны всегда. Подсказки при наведении — `data-tip`; «i»-пузырь в заголовках — `HT(html)`.
- «Листы» — вкладка внутри «Узоров» (переключатель Листы · Очередь · Все рисунки); в колонке разделов их нет, клавиша `1` работает.

## 8. Панель выбранной рамки и двойники (v11.15)
- Справа сверху — **пара «на фото / схема»** (одна картинка фрагмента и одна выбранная схема), под ней название и статус. Схемы-кандидаты справа больше не показываются.
- **Всё, из чего выбирают, — слева**: строка «Поиск узора» над вкладками (словарь: выбранной рамке — сразу, без рамки — «обведите этот узор»; во «Все схемы» тот же текст фильтрует схемы); «Похожие» = «Схемы узора «X»» (если название есть) + «Похоже по форме» — у каждого раздела подпись, почему он здесь.
- **Зона** — выпадающий список (клавиши 1–8 как раньше).
- **Проверка** — две большие кнопки внизу панели, как «Готово → след.» у узоров: «✓ Верно → следующая», «✗ Неверно → следующая» (переход к следующей непроверенной рамке). Показываются только когда у рамки есть название или схема — проверять безымянную рамку нечего. Клавиши C / X — только отметка, без перехода. «Снять отметку» — в «Ещё».
- **Двойники**: в ленте под фото — только значок (✓ ≈ ✗ ?). Вопрос «Это тот же ковёр?» — один раз карточкой поверх фото при открытии ковра с непроверенным двойником; «позже» — до следующего запуска студии. Пачкой — «Ковры → проверить склейки» и «События».

# Ковровое ДНК

База данных азербайджанских ковровых мотивов на основе классификации Лятифа Керимова
и других источников: 4 школы, 144 мотива, ~1300 элементов орнамента.

## Структура данных

- `motifs/{id}.json` — карточка мотива (школа, подгруппа, названия, происхождение, синонимы)
- `elements/{id}.json` — отдельные элементы орнамента, из которых состоят мотивы
- `carriers/{id}.json` — конкретные ковры-носители мотива (музей, дата, размер, провенанс)
- `schools/{id}.json` — описания школ ковроткачества
- `index.json` — сводный индекс всех мотивов, доступен через CDN

CDN: `https://cdn.jsdelivr.net/gh/22adolgikh-pixel/carpevo@main/`

## ⚠️ Статус данных: часть базы — черновик, требует проверки

Часть записей (первые 62 мотива) была собрана прямым запросом к языковой модели по
названию мотива, **без привязки к конкретной странице первоисточника**. Такие записи
помечены полем:

```json
"verification_status": "unverified_llm_generated"
```

Это означает, что даты, музейные номера, размеры и прочие детали в этих записях **не
подтверждены по первоисточнику** и могут быть неточными. Записи без этого поля собраны
методом постраничного извлечения из реальных сканов книг (см. ниже) и считаются более
надёжными, хотя тоже нуждаются в выборочной проверке.

Методология: для книг и сайтов данные извлекаются постранично/поблочно с явной
инструкцией модели не добавлять ничего, кроме того, что написано в источнике, чтобы
минимизировать риск галлюцинаций. Полный реестр источников — в `sources/registry.csv`.

## Авторские права

Репозиторий содержит структурированные факты (названия, датировки, размеры, музейная
принадлежность), извлечённые из указанных источников, а не сканы страниц или дословные
объёмные цитаты из книг — сами источники защищены авторским правом.

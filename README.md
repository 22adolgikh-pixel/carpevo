# cps-data — автокопия работы Carpet Pattern Studio

Эту ветку пишет сама студия (`cps/backup.py`) с Mac, на котором она запущена: раз в 10 минут и при остановке.
Здесь только данные: `data/work/` (рисунки: сетка, пиксели, подписи, привязки к сайту), `data/sheets/` (рамки на листах), `data/legend.csv`, `data/i18n.json`.
Сканы, кропы и картинки `data/out` сюда не попадают: репозиторий публичный, а сканы книг защищены авторским правом.
Код студии — ветка `cps-v5`, папка `cps/`.

# Ковровое ДНК (Carpet DNA)

База данных ковровых мотивов Кавказа на основе классификации Лятифа Керимова.

## Структура
- `/motifs` — мотивы (узоры)
- `/elements` — атомарные элементы
- `/carriers` — конкретные ковры-носители
- `/schools` — школы (Губа-Ширван, Карабах и т.д.)

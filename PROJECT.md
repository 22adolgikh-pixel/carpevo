# Ковровое ДНК

Каталог мотивов, элементов и носителей азербайджанского ковра, извлечённый
постраничным чтением тома I–III «Азербайджанский ковёр» Л. Керимова (548
страниц), дополненный переводом, дедупликацией и сверкой с внешними
источниками.

Репозиторий: `22adolgikh-pixel/carpevo`
Drive: `carpet-dna/output/` (raw_pages_v3, page_images, translations,
visual_pass1, pass2)

## Пайплайн (по порядку)

### 1. Pass 1 — постраничное извлечение (n8n / ранее)
Читает `raw_pages_v3/{volume}/page_NNN.json`, извлекает по каждой странице:
`motifs_mentioned`, `elements_mentioned`, `carriers_mentioned`, `figures`
(подписи рисунков, без координат — рамок вокруг иллюстраций у нас нет).

### 2. Pass 2 — консолидация (Colab, `pass2_consolidate.py`)
Группирует упоминания одного мотива/элемента по нормализованному имени,
сохраняет цитаты и ссылки «том+страница». **Правило 4**: расхождения в
атрибуции школы между страницами фиксируются, не выбираются произвольно.
Нормализация написания (аз-кириллица 1958–1991, известные буквенные пары
е/э, к/ҝ, х/һ, ы/и, ё/е) — на этом же этапе.

### 3. Перевод и канонизация (`translate_names.py` / `translate_elements.py`)
Проход через OpenRouter (`google/gemini-2.5-flash`) по каждому мотиву/
элементу: даёт **каноническое азербайджанское название латиницей**
(`canonical_az` — теперь единственный заголовок везде на сайте, вне
зависимости от языка интерфейса), перевод значения на русский/английский
(`ru_meaning`/`en_meaning`, либо `null`, если модель не уверена — Правило 1),
и транскрипцию для имён собственных (`ru_translit`/`en_translit`).
Стоимость: ~$0.23 на 885 мотивов, ~$0.27 на 1049 элементов.

### 4. Дедупликация по каноническому переводу
Главная находка всего проекта: если два разных id при независимом переводе
получили **одинаковый** `canonical_az` — это тот же мотив, разное написание
в источнике (иногда — на разных языках источника сразу: «Рог» (рус.) и
«Буйнуз» (аз.) оба перевелись как «horn»). Дало наибольшее число слияний
(885→678 у мотивов, 1049→858 у элементов за один проход) — больше, чем все
предыдущие орфографические правила вместе. Каждое слияние проверено вручную
на ложные срабатывания (найдено и исключено: «Крюк»/«Курок» — совпадение
костяка согласных при разном смысле; «Бута»/«Бутаг» — пейсли vs «ветка»,
разные слова).

### 5. Визуальный проход, этап 1 (`visual_pass1.py`)
Для 406 из 548 страниц (у которых есть рисунок) — картинка страницы + текст
→ `google/gemini-2.5-flash` → список декоративных элементов, которые модель
реально видит на иллюстрации (без координат — рамок нет, это отдельная,
более сложная и дорогая задача, требующая vision-модели с локализацией).
Стоимость: ~$0.71 на все 406 страниц.

### 6. Ссылки на первоисточник (`build_scan_links.py`)
Официальный Google Drive API (не смонтированная папка) даёт ID файлов
сканов → карта «страница → ссылка на Drive». Вставлена в каждую цитату и
каждый визуальный элемент.

### 7. Сверка с Wikipedia (вручную, не автоматически)
Алгоритмическое сопоставление между латиницей и кириллицей ненадёжно (та же
проблема буквы «г»/q/g). Категория «Azerbaijani rugs and carpets» — всего
~25 статей, сопоставлены вручную. 12 мотивов получили `external_references`,
2 новых носителя (реальный ковёр «Карачап», Стамбульский музей, инв. E.100)
добавлены с прямой ссылкой на источник.

## Известные пробелы (честно, не решено)

- **~152 мотива (22%) без школы вообще** — Pass 1 не извлёк атрибуцию на
  странице. Не гадаем по соседним страницам (проверено — там вперемешку
  несколько школ, страницы явно сравнительные/сводные).
- **95 мотивов с несколькими школами** — реальные конфликты атрибуции
  (Правило 4), не наша ошибка.
- **Поле школы у отдельных мотивов** всё ещё содержит сырые обрывки вроде
  «Тәб.», «К.—Ш» вместо канонического id — эти конкретные мотивы не
  подхватились изначальной канонизацией школ, чинить нужно отдельно.
- **Подшколы неполны**: реальные категории вроде «Аранская группа»,
  «Борчалы», «Гарачоп» существуют (подтверждено Wikipedia), но Pass 1 не
  извлёк их как атрибуцию школы — это пробел в извлечении, не в чистке.
- **Координат/рамок вокруг элементов на изображениях нет** — визуальный
  этап 1 даёт только список, не локализацию. Этап 2 (рамки) не запускали.
- **Долгий хвост дублей**: дедупликация по переводу почистила самое явное;
  остаются единичные редкие названия, которые никто не проверял вручную.

## Не проверено человеком
Все данные — `verification_status: extracted_pass2_grounded`. Это означает:
цитата и адрес страницы реальны, но связный текст статьи (описание,
эволюция мотива) человеком не написан, и школа/подгруппа при расхождении
между страницами не выбраны произвольно — оставлены как есть.

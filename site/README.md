# Сайт «Ковровое ДНК» — исходники сборки
- `template.html` — страница (код, стили, интерфейс) с местами под данные.
- `build.py` — `python build.py data.json index.html`: подставляет данные в шаблон. Результат публикуется как артефакт.
- `data.json` — термины (1409), алиасы, источники (8), носители (1164), визуальные данные, ссылки на сканы. Версия 44 (2026-10-03, снята с опубликованного артефакта).
  **В публичный репозиторий не коммитится** (цитаты из книг). Хранится в Project «CarpetsCat»: `claude/site_data_v44.json`.
- Пиксельные схемы (`pixel_schemes`) живут в базе артефакта, не в `data.json`; наполняются пакетом из CPS «Каталог → Пакет для сайта».

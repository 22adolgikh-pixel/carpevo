## Как получено
Подписи прочитаны моделью зрения (google/gemini-3.7-flash через OpenRouter, 12.11.2026) по картинке страницы целиком — поэтому ошибки русского OCR с веками (XIX/XX) сюда не попадают. Сборка: `cps/tools/books/build_series.py` → `build_dna_series.py`.

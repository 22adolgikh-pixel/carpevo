Источник добавлен 2026-11-11. Серия «Azərbaycan xalçaları bütün məktəbləri ilə», при поддержке Фонда Гейдара Алиева.

## Части книги (по оглавлению)
- с. 7–86 — история Карабаха и его ковров; фото музейных и частных предметов XVI–XIX вв. (вышивки, «драконовые» ковры «Xətai», «Çələbi»);
- с. 87–236 — коллекция галереи «Sehrli ilmələr» фирмы «Азер-ильме» (дилерская коллекция);
- с. 237–269 — новые ковры «Азер-ильме» (современные копии).

## Доверие
Ниже среднего, как Мурадов 2008: большая часть — дилерская коллекция без инвентарных номеров (3 из 104), с. 237+ — новоделы.
Ценное: технический паспорт ковра (плотность, узел, поле, цвета) — для CPS (`density`, `knot`) и для сравнения пропорций узла.
Фото — только для анализа и обучения. Сборка: `cps/tools/books/`.

# Музей истории Азербайджана АН АзССР. «Ковры и ковровые изделия»

Серия «Памятники материальной культуры Азербайджана», под общей ред. акад. П. А. Азизбековой. Баку, год по скану не установлен (советское издание). Файл QMMI 2885, 21 стр.

## Файлы
| Файл | Что |
|---|---|
| `plates.json` | 6 предметов с подписью (рус.: «Ворсовый ковёр „Биджо“, XIX в. (Ширван)») |
| `glossary_map.json` | 4 названий; новый кандидат: Xançeşni |

## Доверие
Среднее-высокое: музейные предметы, советская атрибуция (как у Керимова). Подписей мало (большинство фото — фрагменты и детали без подписи), размеров и инв. номеров нет.


## 2026-11-13: полная легенда

`legend.json` — все 75 предметов альбома по английской легенде (с. 21 файла): вид изделия, название, век, техника, школа, сверка с моделью. Текст альбома — М. Кулиева, фото — Г. Гусейнзаде. Инвентарных номеров и размеров нет. `plates.json` (6 фото из студии) не менялся: остальные фото альбома в каталог студии не вошли, потому что на страницах по несколько предметов и подписи стоят общим блоком.

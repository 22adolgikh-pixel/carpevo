# «Azərbaycan xalçaları. İrəvan qrupu» (Иреванская группа)

Файл QMMI 2854, 59 стр. Титул и выходные данные в скане не распознаны; в SOURCES_REVIEW 2026-10-06 книга записана как «İrəvan qrupu» (2015), вероятно серия Мурадова «Azərbaycan xalçaları bütün məktəbləri ilə» — **не сверено**.

## Части
- i-3…i-20 — история Иреванского ханства и губернии, переселения (политическая часть, в модель не берётся);
- i-21…i-34 — характеристика ковров по махалам (Агбаба, Шёрейель, Лори, Пембек, Шемшеддин, Гёйча, Зангибасар, Сардарабад, Кырхбулаг, Аштарак, Апаран, Дарачичек, Талын, Зангезур, Даралагёз, Иреван);
- i-35…i-57 — 20 ковров с вытканной датой по хиджре (1201–1326 г. х.), размером и местом.

## Доверие и оговорки
- **Пересчёт хиджры в подписях неверен систематически** (книга прибавляет 579: h. 1201 → «1780» вместо ≈1786/87). Годы из подписей не использовать; века почти верны.
- Книга национально-политическая («Западный Азербайджан»); атрибуция ковров этого края спорна. Модель хранит её как утверждение источника.
- Собрания и инвентарные номера ковров не указаны. Доверие — ниже среднего, но это единственный наш источник по Иреванской группе.

# Прототип «Ковровое ДНК» на понятиях

Сборка: `python3 build_proto.py SITE_DATA.json SCHEMES.json OUT.html "прототип vN"`
(данные: site/model/out — сначала `python3 ../model/build_concepts.py SITE_DATA.json SCHEMES.json ../model/out`).

## Версии и откат
- Каждая опубликованная версия = ветка `versions/proto-vN` в GitHub (снимок cps-v5: код, правила и результаты сборки вместе; теги через прокси не пушатся, поэтому ветки).
  В подвале страницы и в «О модели» указаны метка версии и коммит.
- Откат: `git fetch origin versions/proto-vN && git checkout FETCH_HEAD -- site/model site/proto`, пересобрать и опубликовать в тот же артефакт.
- Артефакт тоже хранит историю публикаций (номер версии и метка), поэтому прошлое состояние можно посмотреть и там.
- Список версий — в CHANGELOG ниже.
